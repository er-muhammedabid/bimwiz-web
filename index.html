What's in each panel

Every tool runs inside its own transaction, with a preview and per-item status log before anything touches the model.

Family

Batch family loading and symbol renaming, working around the Revit 2024 API quirks that break direct name access on families and types.

General

Duplicate element finder and a highlighter for tagged elements, for catching overlap and orphaned tags before a coordination review.

Rooms

Auto-numbering across selected rooms, following the sequence and level rules you set — no manual re-numbering after a layout change.

Sheets

Batch renaming with find/replace, numbering, and regex; sheet and view purpose tagging; PDF/DWG export into timestamped folders.

Views

Tag alignment in true view-space, and dimension tools that respect each view's own orientation rather than assuming model X/Y.

Walls

Batch curtain grid deletion and wall join control, for cleaning up geometry across a whole level in one pass.

Settings + beta

Line style creation, a safety-checked material find-and-replace, and a beta panel for tools still being tested against live files.

Install

Runs on Revit 2024 or later with pyRevit 5.3 or later. The installer checks for pyRevit first and adds it if it's missing.

Install-BIMWiz.ps1 — Setup
1

Download the installer

Grab Install-BIMWiz.ps1 from the latest release.

2

Run it in PowerShell

Right-click the file and choose "Run with PowerShell." It checks for pyRevit and installs it if needed.

3

Open Revit

The BIMWiz tab appears in the ribbon automatically — no manual extension folder setup.

4

Enter a Pro key (optional)

Paste your license key under the Settings panel to unlock the Pro tools. Skip this for the free tier.
